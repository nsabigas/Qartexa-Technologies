QARTEXA WEBSITE - COMPLETE PACKAGE
==================================

This one ZIP contains everything: the website, the Staff Portal, the database
files and all guides. Nothing else is needed.

HOW TO PUBLISH THE WEBSITE (any host)
1. Extract the ZIP. Open the extracted folder: you should see index.html,
   a "css" folder, a "js" folder, an "img" folder and many pictures.
2. Upload EVERYTHING inside that folder to your web host's public folder
   (the folder that must contain index.html at its top level).
   Hosts that take a whole folder or ZIP in one go (Cloudflare Pages "Direct
   Upload", Netlify "Drop", cPanel File Manager, FTP) are the easiest.
   GitHub's website uploader accepts only 100 files per upload (this site has
   more), so with GitHub use "GitHub Desktop" or the command line instead.
3. Open  yourdomain/deploy-check.html  . It checks every file and tells you
   in green or red whether anything is missing.
4. Press Ctrl+F5 on the home page.

You may delete these folders before publishing; the website does not need them:
   docs, tests, tools, supabase   (keep them in your own archive: they hold the
   guides, database setup files and tests).

STAFF PORTAL (editing, Media library, forms, jobs)
Needs a Supabase project. Follow docs/V5-SETUP-GUIDE.md (and docs/V4-SETUP-GUIDE.md).
Without Supabase the public pages still work and look the same.
